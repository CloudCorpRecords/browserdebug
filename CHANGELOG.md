# Changelog

## 0.1.0 (2026-10-26)

- First release: 26 DevTools-style tools (input, navigation,
  emulation, performance traces, network, console, snapshots and
  screenshots) over an injectable DevTools browser executor, with
  the trace state machine and dialog/format whitelists in the core.
- One bin serves the CLI and a stdio MCP server (`mcp` subcommand).
